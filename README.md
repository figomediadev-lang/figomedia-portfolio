## ⚡ Overview & Transformation

This portfolio is an editorial redesign of **FIGO MEDIA**, transitioning the brand from a standard digital marketing studio into a premier **Performance & Social Growth Agency**.

The layout, typography hierarchy, bracketed editorial indexing, and interaction architecture are directly inspired by **[Rohan Nambiar](https://rohannambiar.com/)**, married with Figo Media’s signature **Obsidian Black (`#0c0d0f`)**, **Card Charcoal (`#16171b`)**, and **Electric Cyan (`#00bacc`)** brand identity.

## 🎯 Architecture & Sections

- **Sticky Glassmorphic Nav**: Brand logo, bracketed navigation (`01`–`07`), real-time **Dubai GST Live Clock (UTC+4)**, and direct WhatsApp Consultation CTA.
- **Hero Display**: Editorial typography, micro-crosshairs (`+`), live status beacon, and an interactive **Agency Architecture Index Card**.
- **Infinite Marquee Ticker**: Continuous ticker highlighting core capabilities and UAE/GCC regional focus.
- **( 01 ) Manifesto**: 3 strategic pillars with real performance metrics.
- **( 02 ) Capabilities**: Expanding interactive accordion rows detailing deliverables, business benefits, and channel tags.
- **( 03 ) Selected Work**: Interactive filterable portfolio (`Performance`, `Production`, `Branding`, `Aggregators`) with pop-up Case Study modal detailing challenge, strategy, metrics, and deliverables.
- **( 04 ) In Motion / Showreel**: Video gallery with hover previews and fullscreen high-definition video modal with sound.
- **( 05 ) Platform Ecosystem**: Logo grid of managed food delivery and e-commerce aggregators.
- **( 06 ) Growth Packages**: Engagement models inspired by Rohan's packages (`Social Sprint`, `Performance ROAS Engine`, `Full-Stack Growth Partner`).
- **( 07 ) The Execution Framework**: 5-step process (`01 Discover`, `02 Creative Strategy`, `03 Produce & Cut`, `04 Activate & Scale`, `05 Iterate & Compound`).
- **( 08 ) FAQ**: Interactive accordion answering client questions.
- **( 09 ) Direct Consultation & Contact**: Editorial contact deck with a quick inquiry form that pre-populates and dispatches via WhatsApp (`+971 56 553 3893`).

## 🚀 How to Run Locally

You can preview the site immediately using any local server or simply opening `index.html` in your web browser:

### Option 1: Built-in Node Server
```bash
node server.js
```
Then visit: `http://localhost:3000`

### Option 2: Double Click
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, or Safari.

---

## 🌐 1-Click Deployment (Vercel / Netlify / GitHub Pages)

This project is built with clean, zero-dependency HTML5, CSS3, and ES6 JavaScript.

### Deploying to Vercel:
```bash
npx vercel
```
Or push to GitHub and import the repository into your Vercel dashboard.
